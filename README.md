# Distillation for Medical Reasoning

Official code for the paper:

> **Capacity as the Bottleneck: English-Only Chain-of-Thought Distillation and Cross-Lingual Transfer in Medical Reasoning**

*Submitted to PeerJ Computer Science.*

---

## Overview

This repository studies whether an **English-only** chain-of-thought (CoT) teacher can transfer medical reasoning skills to smaller student models, and how that transfer behaves **across languages** (English → Chinese). We perform **offline sequence-level knowledge distillation (Seq-KD)** from a large teacher LLM into 2B and 9B student models, using **QLoRA** for memory-efficient fine-tuning on a single consumer GPU.

**Key finding:** a 2B student benefits consistently from CoT distillation (cross-lingual transfer succeeds), whereas a 9B student already saturates near the teacher's reasoning capacity and shows only marginal gains on the cross-lingual benchmark (CMExam) — pointing to a **capacity-threshold effect** that bounds the benefit of cross-lingual CoT distillation.

---

## Method Summary

| Component | Setting |
|---|---|
| Teacher | DeepSeek-V4-Flash (284B MoE, via OpenAI-compatible API) |
| Students | Qwen3.5-2B and Qwen3.5-9B |
| Distillation | Seq-KD (offline), CoT reasoning chains as supervision |
| Fine-tuning | QLoRA (4-bit NF4, r=32, α=64, dropout 0.05) |
| LoRA targets | q/k/v/o projections + gate/up/down projections |
| Hardware | 1× NVIDIA RTX 3090 (24 GB) |
| Datasets | MedQA, PubMedQA, CMExam (Chinese), MedMCQA, CBLUE |

## Reproducing the Pipeline

The end-to-end workflow is: **download → generate CoT → distill → evaluate**.

### 1. Download benchmark datasets

```bash
python scripts/download_datasets.py
```

### 2. Generate CoT supervision from the teacher

```bash
export DEEPSEEK_API_KEY="your-key-here"
python scripts/generate_cot_data.py \
    --input data/raw/medqa_train.json \
    --output data/cot/medqa_cot_train.jsonl \
    --model deepseek-v4-flash
```

> **Security:** the API key is read from the `DEEPSEEK_API_KEY` environment
> variable only. Never commit a real key to the repository.

### 3. Distill into a student model

```bash
python src/train_v2.py \
    --model_name Qwen/Qwen3.5-2B \
    --train_data data/cot/medqa_cot_filtered.jsonl \
    --val_data data/cot/medqa_cot_train.jsonl \
    --output_dir checkpoints/medqa-distill-2b-v3 \
    --batch_size 1 --grad_accum 8 --epochs 4 \
    --max_length 2048 --lora_r 32
```

### 4. Evaluate

```bash
python src/eval.py \
    --model checkpoints/medqa-distill-2b-v3/epoch_4 \
    --test_data data/raw/cmexam_test.json \
    --dataset_name cmexam
```

## Datasets

The chain-of-thought reasoning chains generated by the teacher are included under
`data/cot/`:

- `medqa_cot_train.jsonl` — raw CoT chains for the MedQA training set
- `medqa_cot_filtered.jsonl` — filtered chains (9,092 examples) used for distillation
- `medqa_nocot_2b.jsonl` — non-CoT baseline supervision

The benchmark datasets are publicly available and are **not** redistributed here;
fetch them with `scripts/download_datasets.py` (requires the `datasets` library
and network access):

- **MedQA** — https://github.com/jind11/MedQA
- **PubMedQA** — https://github.com/pubmedqa/pubmedqa
- **CMExam** — Chinese medical licensing exam (CMB benchmark)
- **MedMCQA** — https://medmcqa.github.io
- **CBLUE** — Chinese Biomedical Language Understanding Evaluation
